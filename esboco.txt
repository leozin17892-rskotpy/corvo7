Funções:
    fun <tipo_retorno?> <nome>(<tipo> <nome>, ...) { ... }

Variáveis:
    var <tipo?> <nome> = <expr>;
    const <tipo?> <nome> = <expr>;

Retorno:
    - return sempre vence retorno implícito
    - última expressão retorna valor se não terminar com ;

Tipos:
    unsigned: u8 u16 u32 u64 u128
    signed:   i8 i16 i32 i64 i128
classes:
	cmho <nome>(<heranca>(opcional)){
    	cmhr(<nome>){
        	this.nome = nome
        }
        <statico?><tipo?><nome>(<tipo?><nome>){
        	usando parametros do construtor:
            this.nome // se o parametro tem o mesmo nome que a parâmetro da classe
            nome // se o parametro não tem o mesmo nome que o parâmetro da classe
        }
        <clsmethod?><tipo?><nome>(<tipo?><parâmetro>){
        	return classe(<parâmetro>)
        }
        
    }
